# Práctica 01 - Sitio Web Downhill Extreme

Este proyecto corresponde a la **Práctica 01** de la asignatura **Programación y Plataformas Web** en la Universidad Politécnica Salesiana. Consiste en la implementación de un sitio web interactivo sobre *Downhill*, integrado con estilos CSS (Flexbox), un formulario de contacto en PHP y persistencia de datos en MySQL con XAMPP.
